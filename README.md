# Mukund Chaudhary — Resume Analyzer

A beginner-friendly resume keyword analyzer built with Python and Streamlit.

## Features
- Upload a resume in PDF format.
- Select Python Developer, Data Analyst, Web Developer, or Machine Learning Engineer.
- Optionally paste a job description to include its keywords.
- View matched and potential missing keywords.
- Get practical improvement suggestions.
- Download a text analysis report.
- Personalized branding: **Mukund Chaudhary**.

## Important
This is a **rule-based keyword checker**, not an AI model or real ATS simulator. The percentage measures keyword coverage only. A keyword match does not prove proficiency. Add missing skills only when they truthfully describe your abilities.

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Deploy on Streamlit Community Cloud
1. Upload `app.py`, `requirements.txt`, and `README.md` to a GitHub repository.
2. Open https://share.streamlit.io/
3. Click **Create app** and select your repository.
4. Choose your branch (usually `main`).
5. Set **Main file path** to `app.py`.
6. Choose an app URL and click **Deploy**.
